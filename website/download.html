Zur Falcon-Web-App

Du kannst oben jederzeit eine andere Version auswählen.

In drei Schritten startklar

Installer herunterladen

Klick oben auf „Für Windows herunterladen“. Die Datei heißt Falcon-Setup-….exe.

Installer starten

Zeigt Windows „Der Computer wurde durch Windows geschützt“, klick auf Weitere Informationen → Trotzdem ausführen. Falcon ist noch nicht digital signiert.

Loslegen

Falcon startet direkt. Lesezeichen und Passwörter kannst du aus Chrome, Edge, Opera oder Firefox importieren.

Falcon auf dem Android-Handy

APK herunterladen

Öffne diese Seite auf dem Handy und tippe oben auf „Für Android herunterladen“. Die Datei heißt Falcon-Mobile-….apk.

Installation erlauben

Android fragt, ob dein Browser Apps installieren darf. Tippe auf Einstellungen → Aus dieser Quelle zulassen und dann auf Installieren. Falcon ist noch nicht im Play Store.

Anmelden

Melde dich mit deinem Falcon-Konto an – oder erstelle direkt in der App eins. Lesezeichen, Passwörter, Verlauf und FalCoins sind dann auf Handy und PC dieselben.

Falcon auf dem Mac

DMG herunterladen

Wähle oben deinen Mac: Apple-Chip (M1, M2, M3, M4) oder Intel. Welchen du hast, steht unter → Über diesen Mac.

In „Programme“ ziehen

Öffne die heruntergeladene Datei und ziehe Falcon in den Ordner Programme.

Beim ersten Start erlauben

Falcon ist noch nicht von Apple signiert. Klick Falcon im Ordner Programme mit der rechten Maustaste an → Öffnen → Öffnen. Meldet macOS „beschädigt“, gib im Terminal xattr -cr /Applications/Falcon.app ein und starte Falcon erneut.

Falcon unter Linux

Paket wählen

.deb für Ubuntu, Debian, Linux Mint, Pop!_OS · .rpm für Fedora, openSUSE, RHEL.

Installieren

Doppelklick auf die Datei öffnet die Softwareverwaltung. Im Terminal geht es mit sudo apt install ./Falcon-*.deb bzw. sudo dnf install ./Falcon-*.rpm.

Loslegen

Falcon findest du danach im Anwendungsmenü. Neue Versionen meldet Falcon selbst – du lädst sie dann hier herunter.

Falcon auf iOS-Geräten

AltStore oder SideStore einrichten

Falcon für iOS-Geräte gibt es nicht im App Store. Installiere zuerst AltStore oder SideStore – die Anleitung findest du auf altstore.io bzw. sidestore.io.

.ipa herunterladen

Tippe oben auf „.ipa herunterladen“. Die Datei heißt Falcon-Mobile-….ipa.

In AltStore / SideStore öffnen

Öffne in AltStore bzw. SideStore „Meine Apps“, tippe auf + und wähle die .ipa aus. Die App wird mit deiner Apple-ID signiert und installiert.

Alle 7 Tage auffrischen

Mit einer kostenlosen Apple-ID läuft die Signatur nach 7 Tagen ab. AltStore/SideStore frischt sie automatisch auf, solange es ab und zu geöffnet wird.
