Leistung & Game Mode

          

            

              
Game ModeGibt CPU und Arbeitsspeicher für Spiele frei: Hintergrund-Tabs werden nach 30 Sekunden pausiert und später schlafen gelegt, Animationen abgeschaltet. Tabs, die Ton abspielen, bleiben aktiv.

              
            

            

              
Tabs schlafen legen nachGilt, solange Game Mode aktiv ist.

              

            

            

              
Arbeitsspeicher begrenzenÜberschreitet Falcon die Grenze, werden die am längsten unbenutzten Tabs schlafen gelegt. Tabs mit Ton bleiben aktiv.
